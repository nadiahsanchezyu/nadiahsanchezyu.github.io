# Nadiah Sanchez Yu: portfolio site

Everything sits in one folder (no sub-folders):
- index.html: the portfolio (one page)
- profile.jpg, award.jpg, workshop.jpg, panel.jpg, ketupat.jpg, c_*.jpg: photos and campaign visuals
- l_*.png: brand logos
- Nadiah_Sanchez_Yu_Resume.pdf: linked from the menu and footer

## Updating the live site
In your GitHub repository, click Add file, then Upload files, and drag in the files that changed. Files with the same name replace the old ones. Commit, wait about a minute, then hard refresh (Ctrl+Shift+R or Cmd+Shift+R).

## Notes
- The two Instagram embeds only load on the live site, not when index.html is opened straight from your computer.
- A free GitHub Pages repository is public, so avoid putting a phone number on the resume you upload.

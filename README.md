## Updating the live site
In your GitHub repository, click Add file, then Upload files, and drag in the files that changed (keep the images folder structure). Files with the same name replace the old ones. Commit, wait about a minute, then hard refresh (Cmd+Shift+R or Ctrl+Shift+R).

## Notes
- The two Instagram embeds only load on the live site, not when index.html is opened straight from your computer.
- A free GitHub Pages repository is public, so avoid putting a phone number on the resume you upload.
